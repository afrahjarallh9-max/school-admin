# نظام الإدارة المدرسية المتكامل

هذا إصدار أول قابل للتشغيل كخدمة ويب مشتركة بين المديرة والموظفات.

## ما يفعله
- حساب مديرة وحسابات موظفات.
- إضافة الصادر والوارد والنشرات.
- رفع مرفق مع المعاملة حتى 15MB.
- تحديد الموظفات المستلمات.
- الموظفة ترى معاملاتها من حسابها.
- فتح المرفق.
- اختيار: تم الاطلاع / اعتماد / رفض.
- المديرة ترى عدد المستلمات ومن اطلعت ومن اعتمدت.
- قاعدة بيانات SQLite.

## تشغيله على الكمبيوتر
1. ثبتي Node.js.
2. افتحي الطرفية داخل المجلد.
3. نفذي:
   npm install
   npm start
4. افتحي:
   http://localhost:3000

الحساب التجريبي:
اسم المستخدم: admin
كلمة المرور: 123456

## ملاحظات مهمة قبل الاستخدام الفعلي
هذا مشروع جاهز كنواة تشغيل، وليس استضافة سحابية بحد ذاته. لكي تستخدمه المدرسة من أجهزة مختلفة، يجب نشره على استضافة HTTPS.
يجب تغيير JWT_SECRET وكلمة مرور المدير الافتراضية قبل الاستخدام الفعلي.
المرفقات محفوظة على الخادم، لذلك يفضل استخدام استضافة ذات تخزين دائم ونسخ احتياطية.
